# ATM

A simple ATM application written in Java.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Input validation
- Error handling
- Exit the program

## Technologies

- Java
- IntelliJ IDEA
- Git / GitHub

## How to Run

Run the `Main.java` class.
